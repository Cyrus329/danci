## 本地升级
先从正在使用的网页导出最新备份，关闭网页，再将本包解压覆盖原文件夹，保持index.html完整路径不变。
不要使用旧版本备份覆盖更新的进度。

## GitHub网页上传
上传解压后的网页文件，不要只把ZIP放进仓库。
网页上传一次最多100个文件；若使用分批包，先上传三批图片，最后上传核心文件。
https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository

上传覆盖不会自动删除仓库已有的历史报告；它们不会影响新版运行。本包已经排除这些文件。
开发测试与完整历史记录仍保存在此前B149完整包中。
