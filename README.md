# v70 B014 · 手机电脑共用一屏一词存档版

本版基于用户上传的 v70 B013 继续修改，没有更换词库或存档结构。

## 一屏一词迁移到电脑

- “一屏一词专注背词”入口现在手机、平板和电脑都会显示。
- 电脑端使用与手机端相同的一屏一词界面。
- 手机可滑动切换；电脑可直接点击“记住 / 模糊 / 忘了”。
- 电脑快捷键：Shift 显示/隐藏词义，左方向键记住，右方向键忘了，Esc 退出。

## 与普通卡片共用存档

- 专注模式的“记住”直接调用普通卡片的记住动作。
- 专注模式的“忘了”直接调用普通卡片的忘了动作。
- 两种界面共用同一个 `progress.card`、历史记录、每日完成统计和下一次复习时间。
- 点击后会进入原有手机双存档、JSON备份和云同步流程。
- 手机上点“忘了”后同步到电脑，电脑不会再显示旧的高阶段；电脑的新操作也会同步回手机。

## 保留内容

- 全词库 4202 条及完整音标。
- 第四次听写独立分组。
- 手动展开语境、句子标记和句中词库联动复习。
