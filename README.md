## v70 B034 全词浏览独立练习三模式 + 错词重置

- 全词浏览独立练习新增三种方式：看英文选中文、看中文选英文、看中文拼英文。
- 四选一在电脑和手机上均固定为 A/B/C/D 四个选项同一行；小屏自动缩小字号并在单个选项内部换行，但不会拆成两行选项。
- 浏览题序、当前位置、答题统计、浏览错词、收藏和熟词仍使用独立存档 `wordMemoryBrowseQuizV1`。
- 答对只记录在浏览独立存档，不改主学习进度。
- 答错或点“不认识”时，仅清空当前这个词的主学习进度、认识度/拼写度和当前日完成标记，使其重新成为新词；词义、音标、分组、来源和重点标记不删除。
- 主进度重置带 `resetAt` 同步标记，旧设备或云端的较旧学习阶段不会把已重置词恢复成旧的高阶段。
- 全库仍为 4745 条；`word-data.js`、`library-folder-data.js`、`context-id-data.js` 与 B033 字节级一致。
